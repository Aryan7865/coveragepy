Add destructuring to `let` and `const` statements, so that an array or an object map can be unpacked into several variables at once. `let [a, b, c] = value;` binds the elements of an array to the names in order, and `let #{ x, y } = value;` binds each name to the object map property with the same name; `const` works the same way and makes every bound name a constant. The value on the right is evaluated exactly once. An array pattern requires an array with exactly as many elements as there are names, and a map pattern requires an object map; anything else is a runtime error. A property missing from the map is treated the same as reading it with `map.x`, so it gives `()` unless the engine is set to fail on invalid map properties, in which case it is an error. Apart from how they get their values, the names introduced this way must behave exactly like variables declared by ordinary `let` and `const` statements, under all engine settings and optimization levels.
